
# NovaBook Product Landing Page

A responsive laptop product landing page built using HTML5,
Tailwind CSS, CSS3, Flexbox, and CSS Grid.

## Features
- Responsive navigation bar
- Hero section with laptop image
- Product features and benefits
- Customer testimonial examples
- Pricing and call-to-action section
- Responsive mobile menu

## Technologies Used
- HTML5
- Tailwind CSS
- CSS3
- JavaScript

## How to Run
Open index.html in a web browser.

## Note
Product pricing and testimonials are illustrative examples.
